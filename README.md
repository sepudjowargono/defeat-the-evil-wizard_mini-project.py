# 🧙‍♂️ Defeat the Evil Wizard

A turn-based battle game built using Python and Object-Oriented Programming (OOP), where players choose a hero and fight against a powerful Evil Wizard.

---

## 🎯 Project Overview

In this project, players select a character class and battle an Evil Wizard using different actions such as attacking, healing, and using special abilities.

The goal is simple: **defeat the wizard before your health reaches zero.**

This project demonstrates core Python concepts including:
- Classes and objects
- Inheritance
- Methods and attributes
- Game logic and user interaction

---

## 🧠 Features

- Four playable character classes:
  - 🛡️ Warrior  
  - 🔮 Mage  
  - 🏹 Archer  
  - ✨ Paladin  
- Each character has **2 unique abilities**  
- Randomized attack damage for dynamic gameplay  
- Healing system with max health cap  
- Defensive mechanics (shielding and evading)  
- Turn-based battle system  
- Evil Wizard regenerates health and attacks each turn  
- Victory and defeat messages  

---

## ⚔️ Character Abilities

### 🛡️ Warrior
- **Power Strike** – Deals bonus damage  
- **Battle Cry** – Permanently increases attack power  

### 🔮 Mage
- **Fireball** – High damage attack  
- **Magic Barrier** – Blocks the next attack  

### 🏹 Archer
- **Quick Shot** – Attacks twice with reduced damage  
- **Evade** – Avoids the next attack  

### ✨ Paladin
- **Holy Strike** – Strong bonus damage attack  
- **Divine Shield** – Blocks the next attack  

---

## 🧙 Evil Wizard Mechanics

- Regenerates health every turn  
- Randomly chooses between:
  - Basic attack  
  - Dark Spell (bonus damage)  

---

## 🎮 How to Play

1. Run the Python script  
2. Choose your character class  
3. Enter your character name  
4. Select actions each turn:
   - Attack  
   - Use Special Ability  
   - Heal  
   - View Stats  
5. Defeat the Evil Wizard before your health reaches zero  

---

## ▶️ How to Run

1. Make sure Python is installed on your system
2. Download or clone this repository
3. Run the script:

```bash
python evil-wizard-game-code.py
```

4. Follow the on-screen prompts
